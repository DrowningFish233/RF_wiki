理智值系统

理智值是衡量角色精神状态的重要指标，会随着游戏中的各种事件而波动。高理智值提供增益效果，而低理智值则会导致罪孽侵蚀与部分负面效果。

理智值恢复

当生命值大于95%且饱食度>18时,缓慢恢复理智值。

理智值消耗

当生命值小于40%,缓慢降低理智值；当生命值小于20%,理智值降低速率翻倍。

词缀影响

拥有部分特殊饰品时,玩家的理智值会因为饰品的特殊效果,发挥出更大的作用

七罪侵蚀

七罪侵蚀是整合包引入的独特机制，每种罪孽都会以不同方式影响玩家的游戏体验。

暴怒

暴怒的攻击倍率为1.2~2.0，若暴怒被攻击，会给予攻击暴怒的对象「仇恨标记」、「发光」效果,暴怒攻击带有仇恨标记的对象将移除「仇恨标记」与「发光」效果，并造成300%的伤害

色欲

色欲攻击带有「玫瑰」的实体将提升10%的攻击力，攻击带有「染血的玫瑰>的实体将提升20%的攻击力,色欲攻击其他实体将给予「玫瑰>效果，若玫瑰达到5层，则消耗5层「玫瑰」，获得1层伤害强化,若其他实体拥有流血效果，则色欲将给予该实体1层「染血的玫瑰」若层数达到10，消耗10层「染血的玫瑰」给予色欲3层伤害强化，,并对其他实体造成1次该实体流血等级的流血伤害

懒惰

常态攻击倍率为0~0.8；受到伤害达一定程度后获得「起床气」；「起床气」状态下，攻击倍率提升到1~10，投出1的概率等同于投出1以上的概率

傲慢

攻击力大幅提升,但是每次攻击都将降低自身攻击速度,该减益将在停止攻击一段时间后衰减

贪婪

buff等级随时间缓慢提升（10秒提升1级）若被攻击则返回到1级 -增加生物掉落特殊物品的概率（不会造成额外掉落）/级5次 -应用抢夺、海之眷顾等附魔时，钓到好货的概率增加（不会造成额外掉落）/级5次 -吸取经验球，掉落物的距离增加到2格/级 -增加0.35倍更改挖掘方块和杀死生物掉落的经验值/级 -有15%的概率使用法术卷轴却不会被消耗/级

暴食

食用高饱食度食物会增加营养值，营养值会为暴食提供增益且每秒降低1点，若营养值溢出，则暴食获得对应等级的「暴食-过载」

嫉妒

你的攻击会随机掠夺被攻击实体身上的药水效果，无论是正面还是负面，掠夺成功会使你的伤害增加3%，最高200%

自定义装备系统

通过寂静装备，玩家可以自定义装备的属性和特殊效果。

材料分配

使用独特的金属来强化装备的各个方面。每种材料提供不同的属性加成：

  • 神圣金锭：镰刀熟练度+15% 神圣法术强度+10%
  • 魂染钢锭：镰刀熟练度+25% 使你额外获得10点的灵魂护盾,灵魂护盾恢复速率+10% 收集到精魂时所触发效果的额外强度+10%
  • 灌注金锭：根据经验等级提高攻击力,每30级提高1点攻击力,上限900级

特殊效果

为装备添加独特的被动能力和主动技能：

  • 持有凋零合金锭词缀效果时,玩家每20秒会获得一发虎标弹,上限8发,可使用武器技能按键消耗1枚虎标弹来推进自身,并给予自身速度2 攻击会消耗1发虎标弹,造成大额击退并额外造成20%伤害(独立乘区)
  • 受到致死伤害后，清除所有经验，并使使用者获得相当于[经验等级/10]的伤害吸收效果，持续时间为[经验等级]秒，冷却时间600秒
  • 降低玩家移动速度，受击目标会受到反向击退以靠近玩家
